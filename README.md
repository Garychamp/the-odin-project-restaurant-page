# The Odin Project: Restaurant Page

A single-page restaurant website built with plain JavaScript and webpack. All page content is rendered by JavaScript.

**[Live demo](https://garychamp.github.io/the-odin-project-restaurant-page/)**

## Getting Started

```bash
npm install
npx webpack serve
```

Then open http://localhost:8080.

## Build

```bash
npx webpack
```

The output goes to `dist`.

## Built With

- JavaScript (ES modules)
- Webpack 5
- html-webpack-plugin

Part of [The Odin Project](https://www.theodinproject.com/) curriculum.
